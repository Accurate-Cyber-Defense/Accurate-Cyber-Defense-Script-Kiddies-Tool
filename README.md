# Accurate-Cyber-Defense-Script-Kiddies-Tool

“Accurate-Cyber-Defense-Script-Kiddies-Tool is a beginner-friendly cybersecurity toolkit for script kiddies. 
It includes Telegram configuration for alerts, port scanning detection, network monitoring, vulnerability checks, and more.
Designed to teach hacking fundamentals safely, it allows users to experiment, learn, and practice cybersecurity techniques while understanding attack and defense methods responsibly.

**How to clone the repo**

git clone https://github.com/Accurate-Cyber-Defense/Accurate-Cyber-Defense-Script-Kiddies-Tool.git

cd Accurate-Cyber-Defense-Script-Kiddies-Tool

**How to run**

python3 Accurate-Cyber-Defense-Script-Kiddies-Tool.py
